# Fight Tom Pearl (Undertale Edition)

Кроссплатформенная битва с боссом Томом Перлом на движке HTML5 Canvas в стиле легендарных босс-файтов **Undertale** с механикой **Жёлтой Души (Yellow Soul)**.

---

## 🚀 Быстрый запуск (Windows / Linux / macOS)

### 💻 На Windows:
- **Вариант 1 (В один клик)**: Просто дважды кликните по файлу **`start.bat`**.
- **Вариант 2**: В командной строке `cmd` / `PowerShell`:
  ```cmd
  python start.py
  ```

### 🐧 На Linux:
- В терминале перейдите в папку и запустите:
  ```bash
  ./start.py
  ```
  *(или `./run.sh`)*

### 🍏 На macOS:
  ```bash
  python3 start.py
  ```

Сервер автоматически подберёт свободный порт и откроет игру в вашем браузере по умолчанию (`http://localhost:8080`).

---

## 🎮 Управление

| Клавиша | Действие |
| :--- | :--- |
| **Стрелки** / **W, A, S, D** | Перемещение Жёлтой Души внутри боевой арены |
| **Z** / **Пробел** | Стрельба снарядами вверх по Тому Перлу / Пропуск диалога |
| **P** | Пауза / Продолжить |
| **M** | Включить / Выключить звук |
| **R** | Перезапуск битвы (после победы или поражения) |

---

## 👑 Особенности игры
- **4 динамические фазы** боя со сменой музыки, палитры и репликами Тома Перла (1000 HP).
- **10 разнообразных атак**: летающие тарелки, брызги, лазерные перекрестия, самонаводящиеся ракеты, бомбы с таймером, серповидные волны ауры и мега-удары.
- **Индикатор урона «5.0»**: каноничный всплывающий спрайт при попаданиях по боссу и при получении урона.
- **Полная автономность**: всё работает прямо из коробки без сторонних библиотек.
