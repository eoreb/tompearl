# Fight Tom Pearl (Undertale Edition)

Битва с боссом Томом Перлом на движке HTML5 Canvas в стиле легендарных босс-файтов **Undertale** с механикой **Жёлтой Души (Yellow Soul)**.

---

## 🎮 Управление

| Клавиша | Действие |
| :--- | :--- |
| **Стрелки** / **W, A, S, D** | Перемещение Жёлтой Души внутри боевой арены |
| **Z** / **Пробел** | Стрельба снарядами вверх по Тому Перлу / Пропуск диалога |
| **P** | Пауза / Продолжить |
| **M** | Включить / Выключить звук |
| **R** | Перезапуск битвы (после победы или поражения) |

---

## 🚀 Быстрый запуск

В терминале перейдите в папку и запустите скрипт:

```bash
cd /home/towa/tompearl
chmod +x run.sh
./run.sh
```

Игра автоматически поднимет локальный сервер и откроет окно в браузере: `http://localhost:8080`.

Также можно открыть `index.html` напрямую в любом современном браузере.
