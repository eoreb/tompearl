# Fight Tom Pearl (Undertale Edition)

Нативная десктопная игра про битву с боссом Томом Перлом на движке **Pygame-CE (SDL2)** в стиле легендарных босс-файтов **Undertale**. 

Больше никакого браузера — игра запускается прямо в отдельном окне на 60 FPS с поддержкой клавиатуры и геймпадов.

## Как запустить

### На Windows:
- **Вариант 1 (В один клик)**: Просто дважды кликни по **`start.bat`**.
- **Вариант 2**: В командной строке `cmd` / `PowerShell`:
  ```cmd
  python start.py
  ```

### На Linux:
- В терминале запусти:
  ```bash
  ./run.sh
  ```
  *(или `python3 start.py`)*

Лаунчер автоматически настроит зависимости при первом запуске и моментально откроет окно игры.

## Управление

- **Стрелки / W, A, S, D** — движение Жёлтой Души
- **Z / Пробел** — стрельба вверх / пропуск диалога
- **1, 2, 3** — выбор сложности на стартовом экране
- **P** — пауза
- **M** — включить / выключить звук
- **R** — перезапуск после победы или поражения
- **Esc** — пауза / выход

## Сложности

- **ЛЕГКО (ЧИЛЛ)** — 120 HP, мягкая неуязвимость, замедленные атаки и частые хилки (+25 HP).
- **КАНОН (92 HP)** — классический Undertale LV 19, честные тайминги, каноничный урон 5.0.
- **ХАРДКОР (АУРА 5.0)** — 50 HP, бешеные паттерны, без права на ошибку.

## Особенности игры

- **Нативный движок**: аппаратное ускорение через SDL2, честные 60 кадров в секунду без браузерных задержек.
- **Честный хитбокс**: компактное ядро сердца (5.5px) для точного уклонения от плотных атак.
- **4 динамические фазы**: смена музыки, реплики Тома Перла, индикатор HP босса.
- **10 разнообразных атак**: летающие тарелки с осколками, спирали, лазеры, самонаводящиеся ракеты, мега-удары, бомбы с таймером, волны ауры и квадро-бластеры.
- **Индикатор урона «5.0»**: каноничный всплывающий спрайт при попадании по боссу и получении урона.
- **Подбираемый жемчуг здоровья**: парящие хилки на арене, спасающие в критический момент.
- **Оригинальные звуки**: знаменитое интро («Hi, my name is Tom Pearl...») и slowed phonk саундтрек.
