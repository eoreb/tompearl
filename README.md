# Tom Pearl Fight

Фанатский Undertale-файт с Томом Перлом. Желтая душа, стрельба, замедленный фонк, 4 фазы и выбор сложности.

## Как запустить

Потребуется установленный Python (для локального сервера).

- **Windows**: дважды кликни на `start.bat` (или запусти в консоли `python start.py`)
- **Linux**: `./start.py` (или `./run.sh`)
- **macOS**: `python3 start.py`

Игра сама откроется в браузере на `http://localhost:8080`.

## Управление

- **Стрелки / WASD** — ходить
- **Z / Пробел** — стрелять / скипнуть диалог
- **1, 2, 3** — выбор сложности на стартовом экране
- **P** — пауза
- **M** — звук вкл/выкл
- **R** — рестарт

## Сложности

- **ЛЕГКО (ЧИЛЛ)** — 120 HP, мягкая неуязвимость, замедленные атаки и хилки (+25 HP).
- **КАНОН (92 HP)** — классический Undertale LV 19, честный баланс, урон 5.0.
- **ХАРДКОР (АУРА 5.0)** — 50 HP, бешеные паттерны, без права на ошибку.

## В игре

- 4 динамические фазы боя
- 10 видов атак (тарелки, лазеры, волны, бомбы и т.д.)
- Честный Undertale-хитбокс ядра души и подбираемый жемчуг здоровья
- Знаменитое интро и slowed phonk в бою
- Чистый JS + Canvas, работает прямо из коробки без зависимостей
